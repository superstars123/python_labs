# Реализованные функции и стратегии

## 1. Функции сортировки

| Функция | Назначение |
|---|---|
| `lambda x: x.health` | Сортировка по здоровью |
| `lambda x: x.power` | Сортировка по силе |
| `lambda x: x.name` | Сортировка по имени |

---

## 2. Функции фильтрации

| Функция | Назначение |
|---|---|
| `lambda x: x.power >= 10` | Отбор сильных персонажей |
| `lambda x: x.health < 100` | Отбор персонажей с низким здоровьем |

---

## 3. Использованные функции высшего порядка

| Функция | Описание |
|---|---|
| `sorted(..., key=...)` | Сортировка объектов |
| `filter(...)` | Фильтрация элементов |
| `map(...)` | Преобразование коллекции |

---

## 4. Паттерн «Стратегия»

Реализована стратегия:

| Стратегия | Описание |
|---|---|
| `BoostStrategy` | Усиление характеристик персонажа |

Стратегия реализована как callable-объект через метод `__call__`.

Это позволяет:

- использовать объект как функцию;
- хранить параметры внутри стратегии;
- легко заменять алгоритмы обработки;
- добавлять новые стратегии без изменения основного кода.

---

## 5. Методы коллекции `PlayerCollection`

| Метод | Назначение |
|---|---|
| `sort_by(key_func)` | Сортировка по переданной функции |
| `filter_by(predicate)` | Фильтрация коллекции |
| `apply(func)` | Применение функции к каждому объекту |

# Демонстрация работы

## Сценарий 1 — Сортировка

### Что демонстрируется:

- использование `lambda` в `key`;
- сортировка объектов по различным параметрам;
- работа метода `sort_by()`.

### Исходные данные:

Коллекция из 5 персонажей:

- Маша
- Иван
- Анна
- Гоблин
- Король
![Сценарий 1](images/lab05/1.png)
### Результат:

#### Сортировка по здоровью

```python
for p in col.sort_by(lambda x: x.health):
    print(f"{p.name}: {p.health}")
```

#### Сортировка по силе

```python
for p in col.sort_by(lambda x: x.power):
    print(f"{p.name}: {p.power}")
```

#### Сортировка по имени

```python
for p in col.sort_by(lambda x: x.name):
    print(p.name)
```

#  Сценарий 3 — Использование `map()`

### Что демонстрируется:

- преобразование коллекции;
- получение отдельных полей объектов.

### Пример:

#### Получение имен игроков

```python
names = list(map(lambda x: x.name, col))
print(names)
```

#### Получение силы игроков

```python
powers = list(map(lambda x: x.power, col))
print(powers)
```



# Сценарий 4 — Цепочка операций

## `filter → sort → apply`

### Что демонстрируется:

- последовательная обработка данных;
- fluent-интерфейс;
- объединение нескольких операций.

### Шаг 1 — Фильтрация

```python
res = col.filter_by(lambda x: x.power >= 5)
```

### Шаг 2 — Сортировка

```python
res = res.sort_by(lambda x: x.health)
```

### Шаг 3 — Применение функции

```python
res = res.apply(lambda x: x)
```
![4](/images/lab05/4.png)
### Результат:

Коллекция последовательно проходит через несколько этапов обработки без изменения основной логики программы.

# Сценарий 5 — Паттерн «Стратегия»

### Что демонстрируется:

- работа callable-объекта;
- применение стратегии к объектам;
- гибкая замена алгоритмов.

### Создание стратегии:

```python
boost = BoostStrategy(50)
```

### Применение:

```python
for p in col:
    print(boost(p))
```
